## 📘 About

Wox Launcher is a community maintained launcher for Windows. It is developed in the open by contributors who keep the project updated for modern Windows builds. The app stays in the background, listens for a hotkey and shows a search box on top of whatever you are doing. From there you can start applications, jump to folders, search the web, check spellings, convert units or trigger simple scripts through plugins. Recent builds focus on faster indexing, better handling of large start menu collections, a refreshed settings window and plugin compatibility with current Windows 10 and 11 releases.

If you came looking for a Wox Launcher download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything below is written for a normal desktop or laptop setup, no special configuration needed. The installer is a standard Windows setup file, so the process should feel familiar if you have installed other desktop tools before.

**Good for:** keyboard first users · developers who launch many tools · people who want quick web search from the desktop · users with large app collections · anyone replacing the default Start menu search · laptop users on Windows 11 · power users who like plugins

## 🛠 Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Launcher hotkey does nothing | Open settings, check the hotkey field and rebind it to a combination not used by another app. |
| Search results are empty | Rebuild the index from settings, and confirm your app folders are included in the indexing paths. |
| App starts but stays invisible | Move the window position back to the primary monitor from the settings panel. |
| Plugins missing after update | Reinstall the plugin from the plugin store and restart the launcher. |
| High CPU usage after launch | Exclude large network drives from indexing, then restart the app. |
| Launcher does not start with Windows | Enable the "start with system" option in settings and re save the preferences. |
